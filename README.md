# Algoritmi e Strutture Dati in C

## Introduzione

La materia di Algoritmi e Strutture Dati in C è un corso di laurea triennale in Informatica, che si occupa di insegnare agli studenti come progettare e implementare algoritmi e strutture dati in linguaggio C.

## Obiettivi

Gli obiettivi principali del corso sono:

- Imparare a progettare e implementare algoritmi e strutture dati in C
- Imparare a risolvere problemi complessi utilizzando algoritmi e strutture dati
- Imparare a scrivere codice efficiente e ben strutturato

## Contenuti

Il corso è diviso in diverse parti:

- Introduzione ai concetti di base di algoritmi e strutture dati
- Algoritmi di ordinamento e ricerca
- Strutture dati lineari (liste, code, pile)
- Strutture dati non lineari (alberi, grafi)
- Algoritmi di ricerca e ordinamento avanzati
- Laboratori e esercizi pratici
